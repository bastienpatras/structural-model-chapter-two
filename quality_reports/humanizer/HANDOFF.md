## Rules to keep

- Propose, approve, then apply: never apply plugin output to `paper-real-estate/` unprompted.
- Hard gates (placeholders, numbers, reference keys, marker comments) failing means REJECT-CANDIDATE; flags (modals,
  negations, quantifiers, hedges, size, new words) go to the reviewer.
- Do not run the plugin on equations, statements, proofs, tables, captions, citations, macros or marked passages (the
  masking already protects them).
- A clean humanizer result is a readability claim, not a provenance claim (`.claude/rules/writing-with-ai.md`).
- Commits and pushes only on Bastien's request.
