# Explorations

Sandbox for experimental work, per
[`.claude/rules/exploration-folder-protocol.md`](../.claude/rules/exploration-folder-protocol.md):
create → develop → graduate to production / keep exploring / archive as abandoned. Nothing here
yet — this file exists so the directory isn't ambiguous clutter (see `repo-hygiene.md`).

This project's code is Python, not R — the protocol's `R/` subfolder example is illustrative,
not prescriptive; shape each exploration's subfolders (`scripts/`, `src/`, `output/`) to match.
The "quality >= 80" item in the graduate checklist is deferred for now (see `CLAUDE.md` "Quality
gates") — graduation should require tests passing and results replicating within tolerance until
a prose/code quality rubric exists for this project.
