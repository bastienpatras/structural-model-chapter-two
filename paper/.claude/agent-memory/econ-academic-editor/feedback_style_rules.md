The author enforces the following non-negotiable style rules for this paper:

1. No telegraphic signposting or transition phrases. Banned: "This X has a concrete empirical implication:", "It is worth noting that", "We now turn to", "To translate X into Y", "Figure X shows that". State the result or fact directly; explain it after.

2. No bold-paragraph headers acting as bullets (e.g., `\noindent\textbf{Renovation thresholds.}` followed by explanatory text). Write continuous narrative paragraphs that flow into one another.

3. No em-dashes as sentence breaks (no `---`, `—`, `–`). Use commas, semicolons, colons, parentheses, or full stops. Single hyphens for compound words are fine.

4. LaTeX source convention: one long paragraph per physical line.

**Why:** Consistent feedback given during rewrite of §7.5 (sec:policy_empirical). The author views these as fundamental register issues that a Top 5 referee would flag.

**How to apply:** Apply to every prose section edited in this paper, including introduction, body, and conclusion. Check for telegraphic transitions at paragraph boundaries and at the start of sentences that reference a figure or table.
